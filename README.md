# Token Hub

Token Hub — веб-каталог игровых кодов, наград, официальных страниц активации и других легальных способов получения игровых бонусов.

## 🎮 Поддерживаемые игры

Сейчас в базе предусмотрены:

- Roblox
- Fortnite
- Brawl Stars
- Minecraft

Архитектура проекта позволяет добавлять новые игры без переделки интерфейса.

## ✨ Возможности

- 🔎 Поиск игровых наград
- 🎮 Фильтрация по игре
- 🏷️ Фильтрация по категории
- 🎁 Каталог доступных наград
- ✅ Отметка проверенных источников
- 🔗 Переход на официальные страницы
- 📋 Копирование найденных кодов
- 🕘 История открытых наград
- 💾 Сохранение истории в браузере
- 📱 Адаптация под смартфоны и планшеты
- 🖥️ Поддержка компьютеров
- 📲 Установка как веб-приложения
- ❓ Встроенная справка

## ⚠️ Важно

Token Hub не изменяет баланс аккаунтов игр напрямую.

Сайт не может самостоятельно начислять Robux, V-Bucks, Gems, Minecoins или другие игровые валюты.

Если для игры существует официальный способ активации кода, Token Hub направляет пользователя на соответствующую официальную страницу.

Не вводите пароль от игрового аккаунта на сторонних сайтах.
